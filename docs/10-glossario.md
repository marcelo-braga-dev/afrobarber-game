## 1. Termos do jogo

| Termo | Significado |
|---|---|
| **BM$** | Moeda fictícia do jogo. |
| **Atendimento** | Ciclo completo de um cliente: pedido, planejamento, execução, avaliação, pagamento. |
| **Pedido** | O corte que o cliente quer, com preço, tempo, XP, dificuldade e resumo histórico. |
| **Planejamento** | Montagem das etapas do serviço e escolha da ferramenta de cada etapa. |
| **Etapa** | Ação do serviço: Lavar, Pentear, Cortar, Navalha, Acabamento, Definir, Barba, Finalizar. |
| **Minigame "Corte Perfeito"** | Desafio de timing em que o jogador toca alvos no momento certo para executar o corte. |
| **Combo** | Sequência de acertos de 60+ pontos no minigame. |
| **Resultado** | Avaliação do atendimento: Horrível, Ruim, Mais ou Menos, Bom, Maravilhoso, Perfeito. |
| **Reputação** | Nota média da barbearia (0–5), com subnotas de Atendimento, Estrutura e Experiência. |
| **Demanda** | Frequência com que chegam novos clientes; depende de preço, reputação, reformas, clima e contas. |
| **Paciência** | Tempo que o cliente aceita esperar; gera os estados da fila e o humor. |
| **Humor** | Tranquilo, Ansioso, Impaciente ou Irritado, conforme a espera. |
| **Personalidade** | Traço do cliente: Amigável, Calmo, Comunicativo, Exigente, Irritado, Chato, Tímido, Brincalhão. |
| **Fidelidade** | Nível de relacionamento de um cliente pela quantidade de visitas: Novo, Conhecido, Regular, Fiel, Lendário. |
| **VIP** | Cliente especial que paga mais, dá mais gorjeta e tem pouca paciência. |
| **Personagem narrativo** | Morador com história em capítulos: Seu Ribeiro, Kemi, Gabriel, Dona Conceição, Leo. |
| **Biblioteca de Cortes** | Enciclopédia dos 24 cortes, desbloqueados ao realizá-los. |
| **Maestria** | Domínio do jogador em um corte específico, em 5 níveis (até Lenda do Estilo). |
| **Nível do barbeiro** | Progressão geral por XP: Aprendiz da Navalha → Lenda AfroBarber. |
| **Missão** | Meta com três degraus (tiers) e recompensas resgatáveis. |
| **Desafio diário** | Meta renovada a cada dia real, com ranking. |
| **Conquista** | Marco permanente com popup e recompensa. |
| **Reforma** | Melhoria comprada para a barbearia, com bônus permanentes. |
| **Prestígio** | Recomeço opcional após o nível máximo, com uma vantagem permanente (perk). |
| **Evento cultural** | Data do calendário afro-brasileiro que dá bônus no jogo. |
| **BarberBook** | Rede social fictícia onde os clientes postam sobre o atendimento. |
| **Cliente orgânico** | Cliente atraído por posts positivos no BarberBook. |
| **Energia / fadiga** | Disposição do barbeiro; baixa, aumenta o tempo do serviço e impede atender; zerada, causa desmaio. |
| **Desmaio (colapso)** | Queda do personagem quando a energia zera, com perda de tempo. |
| **Crise financeira** | Estado de caixa negativo. |
| **Agenda** | Lista de horários marcados pelos clientes. |
| **Overbooking** | Agendamento acima do limite por hora. |
| **Perdido** | Agendamento em que o cliente não foi atendido a tempo. |

## 2. Barbearia e cabelo afro

| Termo | Significado |
|---|---|
| **Degradê / Fade** | Transição gradual do comprimento do cabelo, do mais curto (embaixo) ao mais longo (em cima). |
| **Skin Fade** | Degradê que chega à pele raspada. |
| **Temple Fade** | Degradê concentrado nas têmporas. |
| **Burst Fade** | Degradê em semicírculo ao redor da orelha. |
| **Line Up** | Linha reta perfeita na frente do cabelo. |
| **Shape-Up** | Contorno com linhas retas e geométricas na borda do cabelo — a "assinatura" do barbeiro. |
| **Pezinho** | Acabamento da nuca e das laterais. |
| **Navalha** | Lâmina para acabamentos e barba. |
| **Black Power / Afro** | Cabelo crespo natural em volume arredondado. |
| **Crespo, cacheado, coily, kinky** | Tipos de textura capilar afro. |
| **Transição capilar** | Processo de deixar o cabelo alisado crescer para voltar à textura natural. |
| **Tranças Nagô / Cornrows** | Tranças rentes ao couro cabeludo em linhas. |
| **Box Braids** | Tranças soltas divididas em quadrados. |
| **Twists** | Mechas torcidas em dois fios. |
| **Twist Out** | Twists desfeitos para formar cachos definidos. |
| **Locs / Dreads** | Mechas que se entrelaçam permanentemente. |
| **Sisterlocks** | Sistema de locs muito finos criado pela Dra. JoAnne Cornwell. |
| **Puff** | Cabelo natural preso em volume. |
| **Conk** | Alisamento químico usado por homens negros nos EUA (1920–1960). |
| **Jheri Curl** | Cacho químico brilhante popular nos anos 1980. |
| **Flat Top / High Top** | Corte com topo plano e alto, ícone do hip-hop. |
| **Turbante / Ojá** | Pano amarrado na cabeça; o ojá tem significado religioso no candomblé. |

## 3. Cultura e história

| Termo | Significado |
|---|---|
| **Diáspora africana** | Dispersão de povos africanos pelo mundo, sobretudo pela escravidão. |
| **Afro-brasileiro** | Relativo à população e cultura negra do Brasil. |
| **Black is Beautiful** | Movimento dos anos 1960 de valorização da beleza negra. |
| **Black Power** | Movimento político negro dos EUA; também o nome do penteado afro. |
| **Consciência Negra** | 20 de novembro, data em memória de Zumbi dos Palmares. |
| **Zumbi dos Palmares** | Líder do Quilombo dos Palmares, símbolo da resistência negra no Brasil. |
| **Candomblé / Umbanda** | Religiões de matriz africana no Brasil. |
| **Afropunk** | Movimento e festival de cultura negra alternativa. |
| **Lei 10.639/2003** | Lei que tornou obrigatório o ensino de história e cultura afro-brasileira nas escolas. |
| **Educação para as relações étnico-raciais** | Prática pedagógica de combate ao racismo e valorização da diversidade. |

## 4. Desenvolvimento de jogos

| Termo | Significado |
|---|---|
| **GDD** | Documento de design do jogo (esta pasta). |
| **Loop de jogo** | Ciclo de ações que o jogador repete. |
| **Pré-alfa / alfa / beta** | Estágios de maturidade: jogável parcial → todas as funções → funções refinadas e testadas. |
| **Build** | Versão instalável do jogo. |
| **Playtest** | Sessão de teste com jogadores reais. |
| **Balanceamento** | Ajuste de números (preços, XP, tempos) para uma experiência justa e interessante. |
| **Tier** | Degrau de uma progressão. |
| **Perk** | Vantagem permanente. |
| **New Game+** | Recomeçar mantendo algum progresso. |
| **HUD** | Informações sempre visíveis na tela. |
| **NPC** | Personagem controlado pelo jogo. |
| **Asset** | Recurso do jogo (modelo, textura, som, dado). |
| **Timing** | Precisão no momento de uma ação. |

## 5. Termos técnicos do projeto

| Termo | Significado |
|---|---|
| **Unity 6** | Motor de jogo usado. |
| **HDRP / URP** | Pipelines de renderização da Unity (alta definição / universal). |
| **ScriptableObject** | Arquivo de dados da Unity usado para cortes, produtos, missões e reformas. |
| **Singleton / manager** | Sistema único que gerencia um domínio (ex.: finanças). |
| **GameBootstrap** | Sistema que inicializa os demais na ordem certa. |
| **NavMesh** | Malha de navegação usada pelos personagens para andar. |
| **Prefab** | Modelo reutilizável de objeto na Unity. |
| **Inspector** | Painel da Unity onde valores são configurados. |
| **PlayerPrefs** | Armazenamento local usado para o salvamento. |
| **Play Asset Delivery (PAD)** | Entrega de pacotes de conteúdo pela Google Play. |
| **Wiring** | Ligação de componentes e referências na cena. |
| **`useMinigame`** | Configuração que escolhe entre minigame e execução por etapas. |
| **`RequestId`** | Identificador de um corte (ex.: `req_black_power_classico`). |
